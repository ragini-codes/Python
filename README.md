# CP1 - FreeCodeCamp Python Certification Project_1

This repository contains my solutions and mini projects completed while working through the FreeCodeCamp Scientific Computing with Python certification.

## Projects

- [User Configuration Manager](cp1_user_configuration_manager.py) - Manages user settings with functions to add, update, delete, and view configurations.
- [Caesar Cipher](caesar_cipher.py) - Encrypts and decrypts text using the Caesar cipher technique.
- [Medical Data Validator](medical_data_validator.py) - Validates medical records by checking required fields, data types, and value formats.
- [Number Printer](number_printer.py) -  Generates a sequence of numbers from 1 to a given positive integer, with input validation.
- [PIN Extractor](pin_extractor.py) - Extracts numeric codes from poems using the lengths of words at specified positions in each line.
- [RPG Character](rpg_character.py)
